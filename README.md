# Cute To-Do 🎀
1. Buka folder ini di Android Studio (Koala / terbaru), tunggu Gradle sync.
2. Colokkan HP atau pakai emulator (Android 7.0+), lalu Run ▶.
3. Android 13+: izinkan notifikasi. Android 12+: aktifkan "Alarm & pengingat" di
   Setelan > Aplikasi > Cute To-Do agar notifikasi tepat waktu.

## Fitur tambahan
- **Ulangi hari kustom**: di form tugas pilih *Custom*, lalu centang hari (Sen–Min) atau pakai preset
  *Setiap hari / Hari kerja / Akhir pekan*.
- **Catatan**: kolom catatan multi-baris + tombol 🎤 untuk dikte (suara → teks).
- **Catatan suara**: rekam/putar/hapus rekaman suara di tiap tugas (butuh izin mikrofon; maks 5 menit).
  Rekaman disimpan di penyimpanan privat aplikasi dan *tidak* ikut file cadangan JSON.
- **Kalender + pencarian**: chip *📅 Kalender* menampilkan kalender bulanan (titik = ada tugas, termasuk
  tugas berulang). Ketuk tanggal untuk melihat tugasnya, ketuk judul bulan untuk lompat tanggal, dan
  kolom pencarian akan menyaring kalender serta menampilkan daftar hasil yang bisa diketuk untuk lompat ke tanggalnya.
- **Night Panda**: memakai color scheme gelap penuh (dialog, menu, chip, kolom teks, status bar) sehingga teks terbaca.
